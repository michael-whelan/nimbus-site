# nimbus-site

Companion site for the Nimbus weather app, served at
[nimbus.michaelwhelan.dev](https://nimbus.michaelwhelan.dev/).

Its job is to host the privacy policy, which Google Play requires as a public URL
before the app can be published.

## Structure

Plain static HTML and CSS, matching the conventions of `michael-whelan.github.io`.
There is no build step, no dependencies and no framework — edit the files and push.

```
index.html                    landing page
policies/privacy/index.html   privacy policy (required by Google Play)
policies/terms/index.html     terms of service
styles.css                    shared styles, light and dark
img/                          brand assets, generated in the nimbus repo
CNAME                         custom domain for GitHub Pages
```

## Hosting

GitHub Pages, serving `main` from the repository root. The custom domain is set by
`CNAME`, which needs a matching DNS record:

```
nimbus    CNAME    michael-whelan.github.io
```

The apex `michaelwhelan.dev` belongs to the `michael-whelan.github.io` user site.
GitHub allows one custom domain per repository, so this subdomain is independent of
it. Add the domain under account settings, Pages, verified domains to prevent
subdomain takeover, and allow a few minutes for HTTPS to be provisioned.

## Keeping it honest

The privacy policy describes real app behaviour and must stay in step with it. If
the app's data handling changes — a new network call, a new third-party SDK,
analytics — update the policy and the Play Data Safety form together.

Brand assets in `img/` are copies generated by `scripts/generate-brand-assets.mjs`
in the app repository. Regenerate them there, then copy across.
